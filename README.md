# 경제 한 입 v3

갤럭시용 설치형 경제 학습 PWA. 7개 이야기형 경제 기초 강의(문맥 속 용어 풀이 포함), 퀴즈, 기기 내 학습 기록, JSON 백업/복원, 뉴스 헤드라인 피드.

## 무료로 배포하기 (GitHub Pages)

1. GitHub에서 새 **public** 저장소를 만듭니다. 예: `econ-bite`.
2. 이 폴더의 **모든 파일과 `.github/workflows/news.yml`**을 저장소 최상위에 올립니다.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**, `main` / `(root)` 선택 후 저장합니다.
4. 수 분 후 `https://사용자명.github.io/econ-bite/`에서 확인합니다. 실제 주소는 저장소의 Pages 화면에 표시됩니다.
5. 저장소 **Actions → Refresh economy news → Run workflow**를 한 번 실행합니다. 이후 워크플로가 하루 두 번(한국시간 오전 7:15 / 오후 7:15) RSS를 시도합니다. GitHub Actions 스케줄은 지연·중단될 수 있고, 피드 URL이 변경되면 수집이 실패할 수 있습니다.
6. 갤럭시 Chrome에서 배포된 HTTPS 사이트를 열고 메뉴의 **앱 설치** 또는 **홈 화면에 추가**를 누릅니다. 브라우저에 따라 메뉴 명칭이 다릅니다.

## 중요한 제한

- 실제 웹 배포, GitHub 계정 연결, 뉴스 수집 실행은 사용자가 설정해야 합니다. 이 ZIP만으로 온라인 주소가 생기지는 않습니다.
- 뉴스는 RSS의 제목·출처·링크를 보여주며 자동 AI 해설을 생성하지 않습니다. RSS 피드의 정상 작동은 보장되지 않습니다. 뉴스 항목은 수집된 시점 기준이며 실시간 속보가 아닙니다.
- 학습 기록은 `localStorage`에 저장됩니다. 다른 휴대폰과 자동 동기화되지 않으므로 기록 화면에서 JSON 백업/복원을 사용하세요.
- 오프라인에서는 설치 후 한 번 이상 로딩된 강의와 앱 화면을 이용할 수 있습니다. 뉴스 갱신에는 네트워크가 필요합니다.
- 업데이트는 배포 시 자동 반영될 수 있지만, 이미 실행 중인 화면은 새로고침이 필요할 수 있습니다.
